# VETOGRAM REBORN — RB8 · Obsidian Atelier

**Date:** 2026-11-05  
**Review branch:** `feature/vetogram-reborn-rb1-foundation-20261105`  
**Existing draft PR:** #235, base is confirmed Vetogram 8.5 reference branch.  
**Deployment:** Not merged. Existing production and 8.5 review server not changed.

## Goal

Deliver the first substantial premium visual redesign **in the existing Vetogram application**, not a separate prototype or a screenshot. The first design milestone covers the real Telegram Chats, contact Stories, fullscreen story media, Stories publishing entry, four-tab navigation and chat composer.

Design direction: **Obsidian Atelier** — graphite/mineral-blue reading surface, precise typography, calibrated material depth, crisp spacing, and limited meaningful motion. Its identity should feel like a well-engineered private messenger rather than a card-heavy marketing dashboard.

## Actual files changed

- **New:** `public/vetogram-reborn-atelier.css`. One final source-scoped presentation layer, loaded *after* all existing styles.
- **Changed:** `public/studio.html` links the stylesheet with a release version and renames the real inbox heading to **«Переписки»**.
- **New:** `tests/vetogram-reborn-rb8-atelier.test.js`, 11 repository source contracts for actual page wiring, controller selectors, four tabs, real chat/Story sources, CSS syntax balance, light themes, wallpapers, reduced motion, hardware/keyboard constraints and honest status labels.

No new UI library dependency, stock images, fake users, synthetic conversations, autogenerated “LIVE” flags or hidden business permissions were introduced.

## Design implementation

**Chat inbox**
- Rebuilt the existing header surface, logo treatment and wordmark as one restrained brand anchor. Removes the redundant decorative live caption; actual owner proof is still in the existing access drawer.
- Feature shortcuts are compact and horizontally scrollable instead of three competing hero cards. All original buttons and event handlers remain.
- Search, filters and list header follow one visual rhythm. Active filters are visibly selected without claiming unsupported counts.
- Real message rows have better contact hierarchy, avatar treatment, time and preview readability, distinct genuine unread badge, retained-copy labels and keyboard focus.
- Existing account connection, archive-degraded state, permissions and error messages retain their original controllers and text.

**Actual conversations**
- Improved the real thread bar, participant title/meta, sync context, reading bubbles, reply actions, composer and send affordance.
- **Never sets the message thread background-image, wallpaper, scroll position, content source, message API or sending rights.**
- Outgoing bubble color uses a restrained cool-blue accent. The chosen pearl/linen appearance receives readable light-surface equivalents. Actual sent/pending/deleted indicators still come from the existing state.

**Contact Stories**
- Cohesive story rail with true Telegram contacts, circular rings, viewed state and original media source. Design does not claim Ghost View if the backend has not verified it.
- Fullscreen viewer now uses contrast-preserving controls, progress, caption and error surfaces. Media is original and unfiltered. RB7 owner/focus and native Back fixes remain intact.

**Stories publishing**
- Real `data-screen="publish"` header, mode switch, Watch area, original publish hero, account-audience state and composer receive the same materials and typography. No auto-publishing or changes to audience/privacy controls.

**Global navigation**
- Four equal main tabs remain **Chats / Stories / Media / Protection**. Deep features stay routed through the original menus.
- Floating-looking dark surface and active states are readable rather than large neon glow pills; safe areas still respected.
- Under 700px, redundant inbox-to-Home exit and the duplicate Archive header icon are hidden; the actual main navigation and Protection remain visible. Under 360px the header emblem is hidden to preserve tap targets and the product wordmark.
- No static desktop assumptions. `visualViewport` keyboard geometry from RB7 is still authoritative; composer positioning and scrollbar are untouched.

## Safeguards and performance

- No runtime JavaScript added for cursor effects, canvas animation, 3D meshes or false information. Visual effects are **CSS-only**, contain no third-party resources and avoid continuous paint loops.
- Blur on the four-tab dock is disabled for coarse pointers to avoid expensive full-width GPU backdrop compositing in Android Telegram WebView.
- Motion reduced under `prefers-reduced-motion`. Focus outlines, forced colors and high contrast are handled.
- Explicit pearl/linen branches for chat rows, message bubbles, Stories publish and bottom navigation. The user's custom wallpaper is not overwritten.
- Scope is explicit: the work does not claim that Cinema, Books, Music, Games or all Privacy views have undergone the same full redesign yet. These need subsequent milestones.

## Verification truth
