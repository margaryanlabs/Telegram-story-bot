## Архитектура

`studio.html` — действующее приложение с 13 screen routes и существующими контроллерами. `app.js` координирует навигацию, публикацию, account/login, общую модальную панель. Чаты и Stories имеют собственные контроллеры и server APIs. Личная MTProto-сессия хранится зашифрованно на сервере; frontend использует подписанную Telegram initData и owner/epoch guards. Vercel serverless не держит постоянное пользовательское соединение: открытая переписка обновляется polling. Backend проверяет владельца, nonce и права отдельно от визуальных переключателей.

Business webhook получает разрешённые новые события; архив сообщений/правок и приватное медиа лежат отдельно. Личный вход не выдаёт Business-права. AI не имеет права молча отправить сообщение: результат остаётся черновиком, а доступ к контексту требует согласия. Voice использует локальные браузерные audio APIs и собственный lifecycle.

## Что исправлено в V5

- Полный SentCodeType/nextType/timeout вместо урезанного SDK sendCode helper; честный канал доставки и ручной разрешённый resend.
- FLOOD_WAIT реального SDK (включая `.seconds`) и долговечное межсерверное ожидание в существующем owner lease.
- Сохранение QR/2FA, прямого успешного входа без кода и границ владельца. Код, пароль, session/hash не выводятся в публичную диагностику.
- Бесконечная рекурсия при закрытии стикеров: исправлено настоящее закрытие drawer.
- Отправка требует сопоставимого Telegram acknowledgement. Неподтверждённый результат не объявляется доставкой, nonce сохраняется для безопасного ручного восстановления.
- Video/audio отправляются с соответствующими MTProto attributes и проверенными ограниченными metadata; пользователь подтверждает отправку.
- Retention применяется при чтении медиа/истории правок, а не только после фоновой очистки. Просроченные и чужие данные недоступны.
- Responses AI явно использует `store:false`; лимиты/согласия/fail-closed режим сохраняются.
- Единый графит/коралл и четыре существующие темы, compact uppercase branding, quieter states, canonical CSS consolidation. Stories watch/create используют существующий strip и редактор, без подставных Stories.
- Полный build gate сохранён: lockfile → AI preflight → syntax → release surface → все tests. Сокращённый beta gate не применяется.
