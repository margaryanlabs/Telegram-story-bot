# V4 — три направления для выбора

Статус: концептуальные изображения показаны в чате 25 октября 2026 года. Это не код V4 и не подтверждение работающих взаимодействий. Порядок соответствует порядку показа изображений.

## 1. Canvas Noir

Иммерсивный холст, минимум chrome, инструменты выбранного объекта поверх/рядом с рабочей областью. Графит + коралл. Подходит для быстрого создания и эмоционального восприятия собственного контента. Риск: не перекрывать важные части фотографии контекстной панелью; фактическая геометрия 9:16 должна отличаться от viewport и проверяться по export renderer.

## 2. Editorial Light

Светлая редакционная мастерская, понятная последовательность фото → оформление → проверка, реальные миниатюры композиций. Светлая тема остаётся полноценной темой NOIR, а не отдельным продуктом. Риск: два конкурирующих действия «Далее» и «Применить» на эскизе; в реализации следует оставить одно первичное действие на состояние. Изображение задаёт направление, но не заменяет инженерную проверку плотности и доступности.

## 3. Layer Desk

Отдельные stage, rail слоёв и inspector выбранного объекта; графит, лиловый selection, коралловое внешнее действие. Подходит для Pro и широкого Fold: inspector переезжает вправо, холст остаётся в центре. На узком экране инструменты раскрываются по выбору. Риск: не превратить профессиональные инструменты в постоянную перегруженную панель; Quick сохраняет меньше элементов.

## Одинаковый сценарий и источники

Каждый вариант показывает редактирование истории с фотографией горной дороги и текстом «Этот момент.». Встроенный генератор изображений получил реальные файлы V3 `studio-mobile.jpg` и `home-mobile.jpg`; первый также получил `chats-mobile.jpg`. Изображения — самостоятельные независимые генерации. Фото в эскизах сгенерированы для art direction, они не пользовательские черновики.

Бриф генераций: мобильный viewport 390×844, только UI без корпуса устройства/OS chrome; русский язык, ясная иерархия, контекстные инструменты, отсутствие глобального dock во время редактирования, никаких вымышленных сообщений, статистики или успешных действий. Различия: immersive canvas / light editorial composition picker / professional layer workstation. Выводы генератора имеют более высокое растровое разрешение, а не доказанный responsive layout.

Перед масштабной разработкой пользователь выбирает один из трёх показанных вариантов. После выбора адаптируем общий язык к Чатам, Личному, Историям, Защите, AI, Голосу, Стикерам, Аналитике, Relay и всем sheets. Не переносим с эскизов потенциально недоступные размеры/контраст/двойные CTA без проверки.
