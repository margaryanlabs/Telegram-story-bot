# Vetogram Music — открытый музыкальный каталог (первый этап)

## Доступно в ветке
- `/music.html` — отдельная адаптивная музыкальная страница Mini App.
- Поиск и жанровые подборки через **Openverse Audio API**, без VK/Яндекс токенов и без хранения ключей.
- Воспроизведение по HTTPS ссылке источника через стандартный HTML Audio, пауза, следующий/предыдущий, перемотка.
- Избранное на конкретном устройстве в localStorage, ссылки на оригинал и Telegram Share.
- Главный экран `/studio.html` → кнопка **Vetogram Music**.
- Динамические результаты; никаких фиктивных треков.

## Важно перед публичным запуском
Openverse индексирует доступные по открытым лицензиям записи, **это не лицензия на каталоги VK или Яндекс Музыки**. Результаты дополнительно ограничены CC0, Public Domain Mark и CC BY. Даже для них необходимо уважать авторство и условия сайтов-источников. Индексация сама по себе не подтверждает правовой статус произведения; требуется процесс жалоб/удаления контента и юридическая проверка перед коммерческим запуском.

Каталог не содержит гарантированно доступных популярных коммерческих хитов. Внешние источники могут не разрешать hotlink/стриминг, возвращать 404, требовать авторизацию или ограничивать регион. Приложение показывает ошибку, а не притворяется, что трек играет. Требуется QA в iOS/Android Telegram WebView.

API может ограничивать запросы по IP (429). Нет бэкенд-кеша или попыток обойти ограничения, нет массового сбора данных.

Приложение **не гарантирует фоновое воспроизведение после сворачивания Telegram**, поскольку поведение зависит от Telegram WebView и операционной системы.

Для VK/Яндекса допустим отдельный интерфейс импорта ссылок/метаданных или официально разрешённый SDK/договор с правообладателями. TraftG/vk-music-bot-api — сторонний исследовательский референс, **не интегрирован**. Не запрашивать VK Admin token через третьи стороны и не передавать пользователям общий секрет VK.
